About
I'm an MCA candidate focused on the path from application code to a running service. I build and document projects that help me practise full-stack development, containerization, CI/CD automation, Linux, and security fundamentals.

I'm especially interested in the intersection of software development, delivery automation, and cloud infrastructure. I value reproducible setup steps, understandable workflows, and honest documentation of what a project currently does.

Demonstrates: Network discovery · Traffic inspection · Security documentation · Remediation planning
